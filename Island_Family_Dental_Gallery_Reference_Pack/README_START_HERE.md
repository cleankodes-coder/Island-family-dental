# ISLAND FAMILY DENTAL — IMAGE REFERENCE PACKAGE

## Critical facts

This ZIP contains **screenshots and crops from screenshots supplied in the chat**. It does **NOT** contain the original full-resolution gallery files from Island Family Dental's official website, Instagram, Facebook or Google Maps. Those sites' image files could not be downloaded in this environment. Do not present these thumbnail crops as original photos or upscale them deceptively.

**The thumbnail folder is for reviewing what appears on the Instagram grid only.** Many posts may depict actual patients, before/after treatment results, or third-party imagery; public re-use is NOT authorized by inclusion in this archive.

- `05_docs_and_tools/AI_STUDIO_IMAGE_IMPLEMENTATION_PROMPT.md` — Google AI Studio instructions

## Steps to obtain original photos, if needed

1. Extract this ZIP on your own Windows computer.
2. In folder `05_docs_and_tools`, run `RUN_ON_WINDOWS.bat` (Python 3 required).
3. If supported by the site's public pages, it will create `original_site_images_unreviewed/` and `Island_Family_Dental_Official_Website_Images_UNREVIEWED.zip`.
4. Open those downloaded images and separately review source, suitability, copyright, and patient permission. The site's CDN may block automation and may have few photos; this downloader cannot guarantee completeness.
5. Upload only approved/authorized photos to Google AI Studio via extracted files and verify paths. Do not pass raw screenshot crops as a real-photo asset collection.
